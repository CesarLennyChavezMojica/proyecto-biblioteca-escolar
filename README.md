# Proyecto Biblioteca Escolar con Ejemplares Irregulares

## Integrantes
- Cesar Lenny Chavez Mojica

## Objetivo
Desarrollar un sistema de gestión para biblioteca escolar que soporte títulos con distinto número de ejemplares sin celdas vacías, implemente ordenamiento por inserción para el catálogo y realice búsqueda binaria por ISBN.

## Estructura de carpetas
- `docs/`: Documentos de diseño preliminar e informes del proyecto.
- `src/` (o solución de Visual Studio): Código fuente del proyecto.
